# 考勤系统前端

基于 React + Vite + Antd Mobile 的移动端考勤签到签退系统

## 技术栈

- React 18
- Vite - 构建工具
- Antd Mobile - 移动端UI组件库
- Axios - HTTP请求库
- Moment.js - 时间处理

## 安装依赖

```bash
npm install
```

## 开发环境运行

```bash
npm run dev
```

访问: http://localhost:5173

## 生产环境构建

```bash
npm run build
```

## 功能特性

- ✅ 签到功能
- ✅ 签退功能
- ✅ 实时状态显示
- ✅ 工作时长计算
- ✅ 移动端适配
- ✅ 美观的渐变UI设计
- ✅ 实时时钟显示

## 界面说明

### 主界面包含：
1. **顶部区域**
   - 实时时钟显示
   - 当前日期显示

2. **状态卡片**
   - 当前签到状态（未签到/已签到/已签退）
   - 签到时间
   - 签退时间
   - 工作时长

3. **操作按钮**
   - 签到按钮（仅未签到时可用）
   - 签退按钮（仅已签到时可用）

4. **温馨提示**
   - 使用说明

## API配置

默认后端地址: http://localhost:3000

可在 `vite.config.js` 中修改代理配置
